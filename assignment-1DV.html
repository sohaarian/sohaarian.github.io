Article

Anscombe’s (1973) Graphs in Statistical Analysis showed me that the presentation of results through data visualization facilitates their perception, evaluation, and communication. While the four data sets described in the article have nearly the same mean, variance, correlation, and regression, their graphical presentation reveals significant differences. Therefore, we cannot rely solely on mathematical results when analyzing data since one might miss vital peculiarities. This fact supports the importance of such statistical software packages as R, which allow exploring patterns and relationships between variables visually. By using code, we can construct informative graphics to estimate the connection between two variables, identify influential points, assess the impact of extreme values, and check the data set for nonlinearity. This method is particularly beneficial for constructing and presenting such statistical software products as dashboards visualizing specific insights through graphics. In this product, we might use these considerations to build informative graphics. However, most importantly, Anscombe’s data sets emphasize the importance of not misrepresenting results. By presenting statistical results through graphics, one must remember that they might contain crucial information that might not be revealed in summary statistics.

Figure 8 from the National Association of Insurance Commissioners’ Report on the Cybersecurity Insurance Market, which compares the percentage of claim closure for primary, excess, endorsement cyber insurance policies, as well as the total has certain strengths and weaknesses (NAIC, 2025). The main strength of this chart is its simplicity since the information is presented in the form of a horizontal bar chart and labeled accordingly. Moreover, the value of each bar is indicated on the chart itself, which allows for faster information retrieval. On the other hand, the key limitation of this graph is the lack of comparison since it only shows the percentage of claims closed for different insurance policies. In the chart, the vertical axis starts at 65%, which narrows the scale and hides the difference in the value of each bar. For instance, compared to endorsement policies, which have a 91.52% closure rate, excess policies only have 76.84%, which is significantly less, but the shrinkage of the bars suggests that the difference between the two is only 15%. The figure above also presents “Total” with an 82.05% closing percentage as if it were another category, which might mislead the interpretation of the data. If I were to develop this chart, I would use a scale that starts at 0% and present the total closing percentage as a reference

Citation: National Association of Insurance Commissioners. (2025). Report on the cybersecurity insurance market.

# Define elements in plant art
# Each image corresponds to a different axiom, rules, angle and depth

# Leaf of Fall

axiom="X"
rules=list("X"="F-[[X]+X]+F[+FX]-X", "F"="FF")
angle=22.5
depth=6


for (i in 1:depth) axiom=gsubfn(".", rules, axiom)

actions=str_extract_all(axiom, "\\d*\\+|\\d*\\-|F|L|R|\\[|\\]|\\|") %>% unlist

status=data.frame(x=numeric(0), y=numeric(0), alfa=numeric(0))
points=data.frame(x1 = 0, y1 = 0, x2 = NA, y2 = NA, alfa=90, depth=1)


# Generating data
# Note: may take a minute or two

for (action in actions)
{
  if (action=="F")
  {
    x=points[1, "x1"]+cos(points[1, "alfa"]*(pi/180))
    y=points[1, "y1"]+sin(points[1, "alfa"]*(pi/180))
    points[1,"x2"]=x
    points[1,"y2"]=y
    data.frame(x1 = x, y1 = y, x2 = NA, y2 = NA,
               alfa=points[1, "alfa"],
               depth=points[1,"depth"]) %>% rbind(points)->points
  }
  if (action %in% c("+", "-")){
    alfa=points[1, "alfa"]
    points[1, "alfa"]=eval(parse(text=paste0("alfa",action, angle)))
  }
  if(action=="["){
    data.frame(x=points[1, "x1"], y=points[1, "y1"], alfa=points[1, "alfa"]) %>%
      rbind(status) -> status
    points[1, "depth"]=points[1, "depth"]+1
  }

  if(action=="]"){
    depth=points[1, "depth"]
    points[-1,]->points
    data.frame(x1=status[1, "x"], y1=status[1, "y"], x2=NA, y2=NA,
               alfa=status[1, "alfa"],
               depth=depth-1) %>%
      rbind(points) -> points
    status[-1,]->status
  }
}
